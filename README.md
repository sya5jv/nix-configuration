# NixOS Configuration Flake

---

## Description

This repository contains a module NixOS configuration flake using `flake-parts` and `import-tree` with the Dendritic pattern (or at least attempting to).

## Hosts

Below are descriptions of all hosts using this flake.

### lemontree

A Lenovo P14s Gen 6 AMD laptop. Currently the only host in the flake so far.
